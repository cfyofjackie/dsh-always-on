# DSH Always On 本机试用

当前本地新构建：0.2.0，构建 20261008.1。提供“任务通知伙伴 / 纯桌宠陪伴”，两种用途都从顶部菜单栏打开设置，不驻留 Dock，不发送系统任务通知。公开 v0.1.0 下载及已安装旧 App 不会随源码改动自动更新。

## 安装与连接

1. 打开新 DMG，把 DSH Always On 拖到「应用程序」，替换旧 App 前先从旧 App 菜单栏退出。也可直接打开项目 `dist/DSH Always On.app`，避免同时运行两个版本。
2. 打开菜单栏 DS 娘头像，在设置底部核对版本 / 构建号。
3. 任务通知伙伴需安装并启动 DeepSeek Harness 0.2.0-rc.2，在设置点“启用集成”，等实际连接。插件内置，无需另行安装 Node。
4. 已启用旧集成时点“更新集成”，在方便时重新打开 DSH，让新 client 的恢复上报生效。App 不会结束 DSH 或正在运行的任务。
5. 纯桌宠陪伴可直接使用，无需 DSH。当前包适用于 Apple Silicon、macOS 14+；其他 DSH 版本尚待验证。开机启动默认关闭。

旧 Native / Pet 设置自动转为任务通知伙伴，未读、配置目录和已启用集成保留；本 App 旧系统通知撤回，不修改系统通知授权或其他 App。

## 两种用途

任务通知伙伴：五种真实任务动作与气泡；空闲后随机演已认可的四种小生活动作。气泡 / 列表可定位具体会话；角色支持拖动、边缘吸附、位置保存、右键菜单。

纯桌宠陪伴：九个现有动作随机切换，避免连续重复；也可在“陪伴动作”固定某个动作。工作、等待、失败只是表演，不产生任务、未读或失败气泡，不显示“DSH 未连接”。隐藏 / 睡眠时暂停，重新可见后重新开始；系统减少动态效果时显示静态动作。点击角色打开设置。

切换用途会收起气泡、停止测试，保留已有未读和集成配置。纯桌宠期间不接收任务提醒；切回任务伙伴时同步最新状态，不补弹这段时间的历史完成事件。

## 点击、未读与等待

点击整块气泡或列表“打开会话”跳回该气泡绑定的 session，角色动作切换不会更改目标。成功跳转只清除点击时已存在的提醒；跳转失败、后台选择或只打开设置不清其他未读。右上角 × 只收起展示，不跳转、不标已读。

点击角色：有气泡时进入该会话；只有一个待关注会话时直接打开，多个时打开列表；没有待关注提醒时进入角色当前会话或打开列表。

问题、批准和计划审阅仍在 DSH 中处理。已读与处理分开：看过问题可以清未读，但 waiting 只有实际处理后才解除。

## 当前前台会话提醒

DSH 在前台、目标会话可见且已加载时，可选择：

- 仅动作（默认）：完成只播放完成动作；失败、问题、批准、计划审阅仍有气泡。
- 动作和气泡：完成也显示气泡。
- 静默：不额外播放通知反馈或气泡，任务状态照常更新。

其他会话照常提醒。仅收到精确查看确认才清未读；内容尚未渲染完或确认超时仍保留未读。旧插件、过期 / 无法识别的前台反馈采用正常任务提醒，不根据“DSH 在前台”猜测会话。

从其他 App 点入 DSH 会先收起已有气泡和完成 / 失败反馈，但不会把所有会话清为已读。

## 全屏显示

设置提供“始终显示 / 仅有任务提醒时出现 / 全屏完全隐藏”。新用户默认仅有任务提醒时出现；旧版全屏开关保留为对应的始终显示或完全隐藏。两种用途共用此设置，纯桌宠若要全屏陪伴请选择始终显示。

仅提醒时出现：在全屏空间平时隐藏，有提醒时显示，收起 / 到期后再次隐藏。完全隐藏：角色与气泡一起隐藏，未读仍在列表中，回到桌面不逐条补弹旧气泡。现在没有系统横幅兜底，选择完全隐藏就不会即时看见任务完成。

目前按 macOS 原生全屏 Space 判断，不根据窗口最大化推断“在看视频”。同 Space 内铺满窗口的视频不能自动分类；独占全屏、多显示器和切回视频的实机结果仍待验收，见 [验证记录](VALIDATION.md)。

## 气泡外观与联合预览

“气泡外观与测试”提供 Q 版蓝白 / 简洁半透明，两款都支持浅深色模式，选择自动保存。完成、失败、提问、批准、计划审阅有五类样例，可以在桌面测试。

打开“动作与气泡预览”，选择九个动作；勾选“同时预览气泡”时，完成 / 失败会显示对应气泡，等待使用上面的提问 / 批准 / 计划审阅选项。工作、待机及生活动作没有任务气泡。

可播放 / 暂停 / 从头播放；测试一直保留到关闭，与真实提醒的 5 秒 / 10 秒独立。样例点击只结束测试，不跳转真实会话，不产生未读。真实新提醒、切换用途或睡眠会结束测试；重开 App 默认关闭。两种用途均可测试。

## 提醒停留与待机小生活

任务伙伴的“桌宠提醒停留时间”默认 10 秒，也可选 5 秒或一直保留直到点击打开。完成 / 失败动作和气泡共用此选择，工作 / 等待随任务变化。到期只收起展示，未读保留；× 可单独关闭，实际处理后撤回过期等待气泡。

永久气泡断线时保留，重开 App 可恢复未关闭、未读的当前气泡；切换用途、进入 DSH、完全隐藏或睡眠会收起展示。新提醒可替换永久气泡，旧提醒仍在列表。

任务伙伴在待机 5 / 10 秒（默认 10）后随机吃饭、扔小鲸鱼、摸头开心、摸小鲸鱼，演完整一轮后回待机重新计时。工作、等待和提醒期间不摸鱼；隐藏 / 睡眠 / 减少动态效果不启动。你操作其他软件也可以触发；鼠标经过不触发摸头动作。此设置与提醒停留时间独立。

## 故障与试用边界

- 未连接：检查 DSH 已启动、配置目录正确、集成已启用；更新集成后重开 DSH。断线会自动重读端点、重新连接，不需要来回切换模式。
- 睡眠 / 锁屏：显示休息状态；收到恢复通知后重建连接，保留游标与未读。连续连接失败才显示断开；实际锁屏后的 DSH 恢复仍待现场验收。
- 等待 DSH 界面：任务连接已建立，准确跳转还需要界面连接。
- 跳转失败：未读保留，显示原因，可重试或自行在 DSH 查找。
- 移除集成：任务伙伴设置中操作，只移除本 App 的注册块，保留其他配置与备份；退出 App 不结束 DSH 任务。

本轮自动检查与隔离原生检查通过；界面测试工具断开，未完成真实前台 / 全屏 / 解锁 / 多显示器验收，也未自动更新已安装 App 或实际插件。细节见 [验证记录](VALIDATION.md)。
