# 0.2.0 · 任务通知伙伴与纯桌宠陪伴

一个 macOS App，两种用途：连接 DeepSeek Harness，用 DS 娘的动作和气泡提醒任务；也可以不连接 DSH，仅让她在桌面陪伴。

## 本版变化

- 新增纯桌宠陪伴：九个已认可动作随机切换，避免连续重复，也可固定动作。工作 / 失败只是角色表演，不产生任务或未读。
- 任务通知伙伴保留完成、失败、提问、批准、计划审阅提醒，点击气泡回到对应会话；加入四种已认可的待机生活动作。
- 收敛为桌宠提醒：移除 Native 系统通知与 Dock 角标，两种用途都从顶部菜单栏进入设置。
- 当前前台会话完成默认仅播放动作；失败和待处理事项仍有气泡，可选择动作和气泡或静默。
- 全屏提供始终显示、仅提醒时出现、完全隐藏；完善睡眠恢复、旧请求边界和连接重试。
- 动作与气泡联合预览，可选择九动作及对应五类气泡，支持暂停 / 重播，不影响真实任务与未读。
- 开发构建的后续备份改存 ZIP，成功打包后移除本次临时副本，减少系统应用搜索收录重复 App；不删除已有备份。

## 下载与升级

附件 `DSH-Always-On-0.2.0-arm64.dmg`，适用于 macOS 14+、Apple Silicon（M 系列）。`SHA256SUMS.txt` 提供文件校验值。

1. 从旧 App 菜单栏退出，再将新 App 拖进「应用程序」替换旧版。
2. 退出安装包中的 App 并弹出 DMG，日常从「应用程序」打开，避免运行多个副本。设置底部核对版本 0.2.0 / 构建 20261008.1。
3. 任务用途需 DeepSeek Harness 0.2.0-rc.2；旧用户点“更新集成”，在方便时重新打开 DSH。App 不停止任务。
4. 旧 Native / Pet 偏好迁移为任务伙伴，提醒记录和集成配置保留；纯桌宠无需 DSH。

## 试用边界

本版为预发布。自动检查、隔离原生状态与构建校验通过；真实 DSH 前台查看、全屏返回 / 视频 / 多显示器和锁屏解锁后的重连仍待完整实机验收。隔离样例不等于真实事件验收，已知边界持续记录在 [验证文档](../VALIDATION.md)。

全屏完全隐藏时没有系统通知兜底，未读仍保留在会话列表；同 Space 内视频铺满窗口不自动识别为原生全屏。仅收到精确会话查看确认才清未读，回答 / 批准 / 审阅仍在 DSH 内完成。

采用本地临时签名，尚未 Apple Developer ID 签名、公证；Intel、Windows 和自动更新未提供。若系统阻止打开，保留提示，不关闭系统安全功能。
