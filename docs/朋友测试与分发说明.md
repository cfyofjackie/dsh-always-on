# 发给朋友测试 macOS App

日期：2026-10-03。本文记录建议，尚未执行打包或发布。

## 怎么安装

可以直接分享 DMG，不必先上架 App Store。朋友下载后双击打开，把里面的 App 拖进「应用程序」，再启动。PKG 则是双击运行安装向导，普通独立 App 通常用 DMG 就够了。

独立 App 如果没有依赖 DSH，朋友就不用安装 DSH；当前 DSH Always On 是通知伴侣，仍需要安装并启动 DSH。

## 先确认朋友的电脑

请朋友打开「 → 关于本机」，提供 **macOS 版本**和**芯片／处理器**两项，不需要序列号。

- 系统：你用 macOS 26 开发，不代表对方也必须用 26。App 可以设定最低版本，例如 macOS 14；旧系统不支持的新功能需要兼容处理，并实际测试。
- 芯片：M 系列需要 arm64 版本，Intel 需要 x86_64 版本。系统版本和芯片是两个独立条件。

## 要不要做 Universal 通用包

| 测试朋友的电脑 | 建议 |
| --- | --- |
| 全部是 M 系列 | 先发 Apple Silicon 版本即可 |
| 同时有 M 系列和 Intel | 考虑 Universal 通用包，双方下载同一个 DMG |
| 暂时不知道 | 先收集电脑信息，再决定 |

Universal 包包含两种芯片的程序；所有随包分发的原生组件也需要兼容。它不会自动让新系统专用功能兼容旧系统，仍需分别测试两种芯片及最低支持系统。

## 签名与费用

少量朋友内测可以先分享未正式公证的包，但首次打开可能被系统拦截。朋友确认来源可信后，可根据提示在「系统设置 → 隐私与安全性」选择「仍要打开」；无法打开时记录提示反馈，不要求关闭系统安全功能。

希望首次安装更顺畅，可以使用 **Developer ID 签名 + Apple 公证**。Apple Developer Program 通常为 **99 美元／年**，当地金额以注册页面为准；会员包含 Developer ID 和公证服务，同一账号可用于多个项目。

## 当前项目与发包前检查

当前 DSH Always On 最低版本设为 macOS 14，打包脚本只生成 M 系列版本，尚未做 Universal 或正式公证。已验证的 DSH 版本为 0.2.0-rc.2；其他系统与 DSH 版本仍需实测。旧 DMG 不包含最新气泡修复，需要重新打包后再分享。「重逢」项目需要单独核对其兼容设置和依赖。

发包前确认：

- 安装包包含要测试的最新改动，文件名标明版本和芯片类型。
- 告知最低系统版本、依赖及首次打开可能出现的提示。
- 请朋友通过实际下载的包测试安装、启动和主要功能。
- 反馈包含 App 版本、系统版本、芯片、复现步骤及错误提示；截图遮住私人信息。
